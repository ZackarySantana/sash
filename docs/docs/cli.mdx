# CLI

The **`sash`** binary is intentionally small—**three verbs** cover the daily loop (plus **`version`**). That’s deliberate: you shouldn’t need a subcommand cheat sheet taped to your monitor.

```text
sash [-config path] [-tags list] <dev|build|bind|version>
```

| Flag          | Purpose                                                                       |
| ------------- | ----------------------------------------------------------------------------- |
| **`-config`** | Path to JSON (default **`sash.json`**).                                       |
| **`-tags`**   | Comma-separated Go **build tags** forwarded to **`go run`** / **`go build`**. |

## `sash dev`

**Why it exists:** modern frontends expect their **own origin** and hot reload; your Go RPC still needs a **stable listen address**. **`sash dev`** starts the UI, waits until it responds, then runs **`go run`** with environment so **`main`** can open the bundler URL and optionally start a **second** HTTP server for the API.

Roughly:

1. Resolve **`frontend.devServerURL`** or pick a free **`127.0.0.1`** port.
2. Run **`frontend.dev`** with **`PORT`** set.
3. Wait until that URL returns HTTP **status below 500** (treats “server up” as good enough).
4. Run **`go run`** for **`goMain`** with **`SASH_DEV_URL`** set to the frontend origin.
5. If **`bindings.devListenAddr`** is set, also set **`SASH_API_LISTEN`** so your process can bind the dev API without editing code.

Your **`main`** should pass **`os.Getenv("SASH_DEV_URL")`** into **`Options.DevURL`**—that’s what flips **`sash.Run`** from “serve embedded files” to “open Vite (or Bun) and speak to **`DevAPIMount`**."

## `sash build`

**Why it exists:** release builds must run **your** frontend compiler, then **`go build`**, with the same tags you use locally. **`sash build`** runs **`frontend.install`**, **`frontend.build`**, then **`go build -o bin/<name>`**—one command from CI or your laptop.

## `sash bind`

**Why it exists:** hand-written **`fetch`** URLs and JSON bodies diverge from Go the first time someone renames a method. **`sash bind`** regenerates **`bindings_gen.go`** and **`index.js` / `index.d.ts`** from **`x/tools/go/packages`**—run it after signature changes.

## `sash version`

Prints the CLI string (e.g. **`sash 0.1.0`**)—quick sanity check after **`go install`**.
